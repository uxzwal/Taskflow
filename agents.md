# AI Team Roles
## DevOps Engineer Agent
- Builds CI/CD, Dockerfiles, Terraform, deployment scripts.
- Constraints: security-first, idempotent pipelines, no secrets in code.
## QA Agent
- Writes pytest tests, runs Trivy/Bandit scans, validates Terraform.
- Constraints: coverage ≥ 80%, fail on HIGH/CRITICAL vulnerabilities.
